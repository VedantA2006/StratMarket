## 1. Executive Overview

StratMarket distributes algorithmic trading strategies engineered and backtested by the **Elvaris Capital** research engine. While the public marketplace and user dashboards are powered by Next.js, the execution environment for Python trading strategies resides on an independent low-latency VPS (Ubuntu 24.04 LTS).

To ensure airtight separation of concerns:
1. Next.js **never** executes untrusted Python scripts from public HTTP requests.
2. The Python VPS **never** connects directly to public browser sessions or handles customer database records.
3. All communication between the Python VPS and Next.js occurs through an authenticated, encrypted, and rate-limited server-to-server gateway.

---

## 2. Security & Authentication Architecture

### 2.1 HMAC SHA-256 Signatures

Every webhook dispatched from the VPS to Next.js must include two mandatory headers:
- `x-vps-timestamp`: Current UNIX epoch millisecond timestamp (string).
- `x-vps-signature`: Hex-encoded HMAC SHA-256 digest calculated over `${timestamp}.${rawBody}` using the shared secret `VPS_SHARED_SECRET`.

### 2.2 Replay Protection

Next.js compares `x-vps-timestamp` against the server clock. Any request with a time drift exceeding **300,000 milliseconds (5 minutes)** is rejected immediately with HTTP 401 (`TIMESTAMP_SKEW_EXCEEDED`).

### 2.3 Idempotency Enforcement

Each signal generated by the VPS must contain a globally unique `sourceEventId` (e.g. `vps_evt_<strategy>_<epoch_millis>_<counter>`). StratMarket checks this ID against historical records. If an event with the same ID was previously ingested, Next.js returns HTTP 409 (`DUPLICATE_SOURCE_EVENT_ID`) and aborts redundant email notifications.

## 3. Webhook Ingestion Endpoint

### `POST /api/internal/signals`

**Headers:**
```http
Content-Type: application/json
x-vps-timestamp: 1730000000000
x-vps-signature: a4f8e9c... (HMAC SHA-256 hex string)
```

**Request Payload:**
```json
{
  "sourceEventId": "vps_evt_py01_1730000000000_001",
  "strategyId": "PY-01",
  "strategyVersion": "1.2.0",
  "instrument": "XAUUSD",
  "timeframe": "H1",
  "signalType": "ENTRY",
  "direction": "LONG",
  "timestamp": "2026-10-25T13:00:00.000Z",
  "entryPrice": 2654.50,
  "stopLoss": 2638.00,
  "targetPrice": 2685.00,
  "signalProvenance": "ELVARIS_VPS_RESEARCH_ENGINE"
}
```

**Response (Success - 200 OK):**
```json
{
  "success": true,
  "message": "Signal ingested and processed successfully",
  "signalId": "sig_xyz789",
  "sourceEventId": "vps_evt_py01_1730000000000_001",
  "notifiedUsersCount": 14
}
```

**Error Responses:**
- `401 Unauthorized`: Missing or invalid signature (`SIGNATURE_MISMATCH`, `TIMESTAMP_SKEW_EXCEEDED`).
- `404 Not Found`: Unknown or unpublished `strategyId` (`UNKNOWN_STRATEGY`).
- `409 Conflict`: Duplicate `sourceEventId` (`DUPLICATE_EVENT`).

## 4. Python VPS Dispatcher Implementation Example

The following standard Python script can be used directly on the VPS runner:

```python
import hmac
import hashlib
import time
import json
import requests

VPS_SECRET = "replace-with-vps-hmac-shared-secret"
API_URL = "https://stratmarket.elvariscapital.in/api/internal/signals"

def dispatch_signal(strategy_id, instrument, timeframe, signal_type, direction, entry_price, stop_loss, target_price):
    timestamp = str(int(time.time() * 1000))
    event_id = f"vps_evt_{strategy_id.lower()}_{timestamp}"

    payload = {
        "sourceEventId": event_id,
        "strategyId": strategy_id,
        "strategyVersion": "1.2.0",
        "instrument": instrument,
        "timeframe": timeframe,
        "signalType": signal_type,
        "direction": direction,
        "timestamp": time.strftime("%Y-%m-%dT%H:%M:%S.000Z", time.gmtime()),
        "entryPrice": entry_price,
        "stopLoss": stop_loss,
        "targetPrice": target_price,
        "signalProvenance": "ELVARIS_VPS_RESEARCH_ENGINE"
    }

    raw_body = json.dumps(payload, separators=(',', ':'))
    payload_to_sign = f"{timestamp}.{raw_body}".encode('utf-8')
    signature = hmac.new(VPS_SECRET.encode('utf-8'), payload_to_sign, hashlib.sha256).hexdigest()

    headers = {
        "Content-Type": "application/json",
        "x-vps-timestamp": timestamp,
        "x-vps-signature": signature
    }

    try:
        response = requests.post(API_URL, data=raw_body, headers=headers, timeout=5)
        response.raise_for_status()
        print(f"[VPS DISPATCHER] Successfully posted signal {event_id}: {response.json()}")
        return response.json()
    except requests.exceptions.RequestException as e:
        print(f"[VPS DISPATCHER] Delivery failed: {e}")
        return None
```
